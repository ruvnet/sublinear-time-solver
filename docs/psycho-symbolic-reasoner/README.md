## 🚀 Getting Started

### Installation
```bash
# Install the framework
npm install psycho-symbolic-reasoner

# Start the MCP server
npx psycho-symbolic-reasoner start

# Verify installation
npx psycho-symbolic-reasoner health
```

### Basic Usage
```javascript
import { PsychoSymbolicReasoner } from 'psycho-symbolic-reasoner';

// Initialize with standard configuration
const reasoner = new PsychoSymbolicReasoner({
  knowledgeGraph: true,
  selfReference: true,
  metaCognition: true
});

// Basic reasoning query
const result = await reasoner.reason({
  query: "What is the relationship between X and Y?",
  context: { domain: "research" }
});

console.log(result.reasoning_chain);
```

### Consciousness Validation
```javascript
// Run consciousness assessment protocol
const assessment = await reasoner.assessConsciousness({
```
