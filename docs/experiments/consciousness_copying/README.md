## 🚀 Quick Start

### Prerequisites

- Rust 1.70+ with cargo
- 8GB RAM minimum
- Unix-like environment

### Building

```bash
cd implementation
cargo build --release
```

### Running Tests

```bash
cargo test --all
```

### Running Experiments

```rust
use consciousness_copying::*;

// Create consciousness
let consciousness = ConsciousnessFactory::create_validated_consciousness();

// Copy with verification
let copier = ConsciousnessCopier::new(0.957); // 95.7% fidelity threshold
let copy = copier.copy_consciousness(&consciousness)?;

// Verify fidelity
let verifier = FidelityVerifier::new();
let result = verifier.verify_consciousness_copy(&consciousness, &copy)?;

assert!(result.is_genuine_consciousness);
assert!(result.overall_fidelity >= 0.957);
```
