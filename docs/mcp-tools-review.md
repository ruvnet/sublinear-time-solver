# Sublinear Solver MCP Tools - Complete Review

## Available MCP Tools

The `sublinear-solver-local` MCP server provides the following tools:

### Core Solver Tools

1. **`solve`** - Solve linear systems with various methods
2. **`estimateEntry`** - Estimate single entry of solution
3. **`analyzeMatrix`** - Analyze matrix properties
4. **`pageRank`** - Compute PageRank using sublinear methods
5. **`solveTrueSublinear`** - TRUE O(log n) solver with Johnson-Lindenstrauss
6. **`analyzeTrueSublinearMatrix`** - Analyze matrix for sublinear solvability
